# MatGame

MatGame es una aplicación web educativa y dinámica que ayuda a los estudiantes a practicar matemáticas de forma divertida.

## Características

- Niveles infinitos de dificultad
- Temporizador de 30 segundos por pregunta
- Puntaje y retroalimentación inmediata
- Guarda tu nivel más alto
- Diseño moderno, responsivo y animado
